# Git 工具：對照 Fork 的功能待辦

以 [Fork](https://git-fork.com)（macOS／Windows 的 Git 圖形工具）為參考，列出 Git 工具已補上與還可以補上的功能。
完成的項目打勾；每一項都有 `npm test` 的實際儲存庫測試，畫面以測試頁實際操作驗證過。

圖例：🔴 優先　🟡 常用　🟢 進階　⚪ 暫不做（說明原因）

## 1. 標籤（🔴 優先）

- [x] 標籤右鍵「推送到 <遠端>」（`git push <remote> refs/tags/<tag>`）；遠端已有同名但指向不同提交時詢問是否取代
- [x] 只刪除遠端標籤（`git push <remote> --delete refs/tags/<tag>`），刪除本機標籤時可一併刪除遠端
- [x] 推送所有標籤（`git push <remote> --tags`）：標籤群組的按鈕、標籤選單、推送對話框的勾選
- [x] 建立標籤對話框的「建立後推送」
- [x] 推送對話框：選遠端、勾選「推送所有標籤」「強制推送」；記住上次的勾選
- [x] 線圖上標籤與分支標記的右鍵選單
- [x] 比對遠端標籤（`ls-remote --tags`）：標示「未推送」與「只在遠端」

## 2. 暫存區：Unstaged ／ Staged（🔴 優先）

- [x] 逐段暫存、取消暫存、捨棄
- [x] 逐行暫存、取消暫存、捨棄（點行號選取、拖曳多選、Shift 連選）
- [x] 保留換行字元、BOM 與執行權限；暫存時套用 `core.autocrlf` 等轉換
- [x] 檔案清單多選與批次操作；鍵盤 ↑↓、Space／Enter、Delete、⌘A、Esc
- [x] 清單／樹狀檢視；篩選檔名
- [x] 右鍵加入 .gitignore（檔案、副檔名、資料夾）
- [x] 儲藏選取的檔案
- [x] 提交選項：提交後推送、`--signoff`、`--no-verify`；按鈕顯示檔案數；摘要超過 72 字提示；最近使用的訊息
- [x] 假設未變更（`update-index --assume-unchanged`）與取消
- [x] 圖片差異（並排顯示新舊圖片）

## 3. 提交右鍵選單（參考 Fork 截圖）

- [x] 存成 Patch（`git format-patch -1`）
- [x] 與工作目錄比較（Compare to Local Changes）
- [x] 複製提交編號、短編號、訊息
- [x] 互動式重定基底（重新排序、squash、fixup、reword、drop）
- [x] 修改提交訊息（最新的提交直接修正；較早的提交以重定基底改寫）
- [x] 把目前分支重定基底到這裡（也在分支選單：重定基底到某個分支）
- [x] 參照的選單：在線圖的分支／標籤標記上右鍵（取代 Fork 的子選單）

## 4. 側欄（🟡 常用）

- [x] 分支依「/」分資料夾、可收合
- [x] 篩選分支、遠端分支、標籤、子模組
- [x] 子模組清單、初始化與更新、開啟
- [x] 工作樹清單、新增、開啟、移除

## 5. 差異比對（🟡 常用）

- [x] 忽略空白
- [x] 自動換行切換（不換行時左右捲動，並排兩側保持對齊）
- [x] 檔案歷史（跟著重新命名）
- [x] 逐行追溯（blame），可以看工作目錄或某個提交當時的版本
- [ ] 語法高亮（需要內建語法剖析器，檔案變大；先觀察需求）

## 6. 推送／拉取／擷取（🟡 常用）

- [x] 推送對話框
- [x] 拉取對話框：選遠端分支、合併／重定基底／只允許快轉
- [x] 擷取並刪除遠端已不存在的標籤（`--prune-tags`）

## 7. 進階（🟢）

- [x] 比較任意兩個提交（「設為比較的起點」）、分支與目前分支比較
- [x] 參照紀錄（reflog）：建立分支、切換、重設回某個紀錄
- [x] 在全部歷史中搜尋訊息、作者、檔案內容（`-S`）
- [x] 在終端機開啟儲存庫或檔案所在的資料夾（設定 `gitTool.terminal`）
- [ ] 自訂指令（Fork 的 Custom Commands）：需要先設計安全的參數代換與確認畫面
- [ ] 多個儲存庫以分頁同時開啟（Fork 的上方分頁列）：目前用下拉選單切換；需要把畫面狀態改成每個儲存庫各一份

## ⚪ 暫不做

- Git LFS、git-flow：使用者少，且需要額外安裝的程式。
- 頭像（Gravatar）：需要把 email 雜湊送到外部網站，不符合「只有 clone／fetch／pull／push 等 Git 操作會連線」的原則。
- GitHub／GitLab 帳號整合、建立 Pull Request：帳號權杖不由這個擴充保存。
